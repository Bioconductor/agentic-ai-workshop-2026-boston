# Contributing

Contributions to the workshop site and materials are welcome.

## How

1. Fork (or branch, if you have write access) and edit — pages are
   Quarto markdown (`.qmd`) files; site config is `_quarto.yml`.
2. Preview locally with `quarto preview` (requires
   [Quarto](https://quarto.org)).
3. Open a pull request. The site publishes automatically from `main`
   via GitHub Actions.

Small fixes (typos, broken links) are fine as direct PRs with no prior
discussion. For larger changes — new pages, restructuring, added
materials — please open an issue first.

## Ground rules

- All interactions are governed by the
  [Bioconductor Code of Conduct](https://bioconductor.org/about/code-of-conduct/).
- Content is dedicated to the public domain under
